# Dual-lane adjudication

Run `piggery skills dual-lane-adjudication` for the installed Lead playbook. The command only
prints instructions; it launches no team or model. Use `piggery skills` for native tools.
If unavailable, report the missing capability without installing or restarting Piggery.

Use the supplied scope or the current task's hard question. A leading `prepare` means brief
only, with no workers. The Lead chooses two useful angles on one neutral brief and verifies two
different model families; defaults are GPT-6-astra and Claude Opus 5.5. Collect both independent
reports before sharing findings, send each material conflict to the other side, and iterate
bounded evidence checks. Resolve on evidence, retain dissent when warranted, and stop when
further exchange adds no information. There is no third lane or OCR requirement.

Keep the brief/snapshot and exact participant/run/message return bindings from the playbook.
A session/team root need not equal a code candidate's Git root. Preserve another team's
contract; use it only if it permits this method, otherwise prepare a separate-session handoff.
Use existing task and delegation authority. Discovery does not grant permission to edit a
review-only candidate, publish, merge, or change unrelated work. The Lead owns authorized
implementation and verification after adjudication. Treat optional scope as literal user text,
never interpolate it into a shell command.
