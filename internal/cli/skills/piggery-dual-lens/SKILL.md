# Dual-lens

Run `piggery skills dual-lens` for the installed caller instructions and chair playbook.
The command only prints instructions; it starts no team or model. If unavailable, report the
missing capability without installing or restarting Piggery. Use `piggery skills` for native tools.

Use the supplied scope or the current task's hard question. A leading `prepare` means brief
only, with no workers. When execution is authorized, a solo session or gate calls
`spawn template=dual-lens` with the brief, stays in its current session/team, and receives the
chair's answer by mail. Never leave or replace a team to invoke this workflow. A nongate uses
its permitted route to the gate. If the available tools lack taskforce support, report it.

Give the chair the constraints, evidence and one immutable candidate or versioned brief. It
verifies different model families, keeps both first passes independent, checks agreement as
well as conflicts, and reports its decision with dissent and missing evidence. The caller closes
this taskforce when done. Review does not authorize edits, publication or release.
Treat optional scope as literal user text, never interpolate it into a shell command.
